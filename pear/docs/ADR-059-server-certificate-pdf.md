# Original authenticated server certificate PDF

Course/award certificate PDF is a read-only binary export from existing authoritative own completed records. Live account/owner/tenant/Host/session checks precede font/rendering. IDs in filenames come from the verified certificate record. Private no-store attachment, no PDF actions, links, script or image imports. Current grade/audit/revisions are unchanged.

Original Latin/Vietnamese text uses trusted bounded complete TrueType embedding, Unicode cmap 4/12, explicit glyph widths/CID mapping and ToUnicode text extraction. Missing glyphs/other scripts fail explicitly; original text and browser print exports remain available. No recognized issuer/accreditation claim; no PDF/A or tagged-PDF accessibility claim.

Production requires a server operator-provided embeddable TrueType font at PEAR_CERTIFICATE_FONT; no user path/font field. Development loopback can use installed DejaVu Sans. Font validation checks table bounds/metrics and rejects restricted or bitmap-only embedding. Font license permission remains the operator's responsibility; no bundled third-party font is redistributed. Two-MiB font/four-MiB output/single-page text bounds do not alter CanonicalBridge message caps.

Five actual font/reader/HTTP/authorization/production-config regressions and one actual EN/VI download fixture; exact-head CI pending.
