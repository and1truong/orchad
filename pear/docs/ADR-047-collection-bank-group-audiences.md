# ADR-047: group collections, banks and scheduled obligations
Epic #49 G04/G06/G08/G09/G12/G13. Extends ADR-046.

Playlists/awards/question banks declare bounded one-to-eight same-tenant group audiences. Current static/dynamic membership gates learner collection discovery/activity and scoped staff bank reads/application; learners still have no bank tools or answer-key API. Existing authors/administrators keep their explicit review responsibilities. Course/item/bank/nested-award reuse rejects a wider receiving group set or public audience; author-only sources remain same-owner private. Group quiz extraction can create a same/narrower group bank with immutable provenance.

Own award group activity and recipient assignment check current membership before original-key replay. Existing own ledger/evidence/certificate history remains retained; active new evidence or child-course enrollment is denied after membership loss. An authorized assessor can still review previously submitted evidence under existing explicit scope. Group source snapshots and official outcomes are never silently rewritten.

Scheduled group awards validate every initial recipient, recheck current pinned and published target audience on reconciliation, withdraw unfinished obligations when rights disappear and reactivate the same records on rejoin. Completed history stays completed and repeated scheduler calls remain deduplicated. Author-only scheduled awards retain the prior unsupported restriction. Root group/child group containment is conservative by declared group IDs, not inferred equivalence of dynamic rules.

Six domain/actual HTTP/scheduler and one author/learner EN/VI mobile browser regression are authored. Human editors expose explicit group IDs; no membership roster is copied into content tools. Cross-portal licensing/sharing and actual provider/reference reset/recertification semantics remain OPEN/NOT VERIFIED. Default media/bridge caps and generic mutation invariants remain unchanged.
