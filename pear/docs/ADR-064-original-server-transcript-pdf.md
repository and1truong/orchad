# ADR-064: Download an original own-ledger PDF using an authenticated snapshot
Status: implemented, exact-head CI pending.
Own transcript PDF uses the existing report service's current own-ledger scope and exact snapshot hash. Submitted rows, principal IDs and content bodies are never accepted. The same hash is checked on every bounded page; change aborts the entire export. At most 500 records, 65536 characters, 40 pages and 4MiB; larger documents explicitly retain CSV/browser print alternatives.
The existing trusted-font certificate renderer becomes a bounded text-document engine with shared font embedding and page resources. Existing certificates retain their single-page profile. Latin/Vietnamese text, literal markup, CID mapping and ToUnicode are preserved; unsupported scripts and missing trusted production font fail explicitly. No external font/model/provider requests.
The download route retains Host, cookie and epoch/current-account checks and sends private/no-store/nosniff attachment headers. UI guards current workspace/session before and after response/body awaits and does not dispatch a download after detach/logout. No learning state, scores, receipts or certificate issuance changes.
Own ledger rows show historical status, source, pinned version, dates, score/progress/earned values, intended time and measured timer values with explicit development/no-accreditation disclosure. This is not a reference layout, accredited transcript, PDF/A, tagged PDF or unrestricted admin/report PDF parity.
