# ADR 004 — User profiles, lifecycle and groups

Status: implemented for the synthetic development portal; production identity remains an external integration gate.

Admin creates/updates same-tenant identities, names, roles, active state, manager relationships and bounded custom fields. Identity IDs are immutable globally; an existing identity in another tenant cannot be reassigned. User security changes increment auth_version, delete sessions and advance the user's learning revision while preserving enrollments, attempts, evidence and certificates. The organization must retain an active admin. Managers must be active same-tenant manager/admin accounts; manager chains cannot cycle. Reassign reports before deactivating/downgrading their manager. Synthetic newly provisioned accounts use the existing explicit loopback development credential policy; production login never falls back to it.

A learner may update only their own preferred content language and up to eight interests. They cannot alter org fields, manager, role or active state. Admin/manager roster reads omit credentials, sessions and auth-version data; managers see only direct reports. Content admins and assessors do not gain people-management rights. Custom profile fields are admin-owned, bounded to eight unique field names. Profile data survives reopening through additive migration 004; missing seed profiles use the documented baseline creation date and are backfilled idempotently.

CSV import accepts an exact eight-column header: id,name,role,active,managerId,preferredLanguage,interests,customFields. Interests/customFields are JSON arrays in correctly quoted CSV cells. The parser accepts escaped quotes and embedded newlines and rejects malformed quoting, column counts and duplicate identities. At most 100 identities and 16,000 characters per batch. Dry-run returns row errors and a hash bound to the CSV, tenant and live identity/profile snapshot. Invalid or stale reviews cannot import. All valid identities and forward manager references are validated as one proposed graph and saved in one audited transaction; partial import is not supported. Import audit stores the review hash, not CSV/profile text. User lifecycle audit records identity/role/active state. Export uses authorized paginated reads, and human UI collects all pages into one CSV download. Spreadsheet formula-leading cells are escaped with an apostrophe; exported values are consequently safe for spreadsheets, rather than a byte-identical round trip of formula-shaped names.

Groups are static identity sets or dynamic ALL/ANY rules with no fixed members. Every group filters inactive members. Rules compare name/role/manager/active/custom fields and UTC creation dates using equals/notEquals/contains/before/after where supported. A missing custom field never matches, including notEquals. Calendar date validation rejects invalid dates rather than normalizing them. Group definitions have versions; saving rules is admin-only. Preview is read-only and paginated; managers see only their audience, and static group definitions returned to managers exclude other member IDs. The human editor requires a successful preview of its current rule draft before saving. Backend still validates every write and CAS protects concurrent library changes.

These are internal lifecycle/group capabilities. Provider provisioning, invitations, production credentials, SSO/SCIM, cross-portal sharing, localization and scheduled group assignment are separate capabilities, with their own evidence. No outbound email or paid service is activated.

Evidence: people.test.ts covers lifecycle/revocation/history, relationship/last-admin/tenant validation, preferences/CAS/rollback, quoting/error-row/stale-review/forward-reference CSV, formula-safe export, static/dynamic ALL/ANY/custom/date rules and active/direct-report membership. http.test.ts verifies deactivation through the authenticated controller revokes a live session. people.spec.ts exercises real human create/profile/custom-group preview/save/import/export and manager/learner separation.
