# ADR-052: Interactive unsaved author quiz preview
Epic #49 G06/G12/G16; base PR #110.

The author draft preview now supports actual practice responses for original single/multiple-answer MCQ, matching, mixed free/dropdown blanks and long answers. Each preview is an isolated copied snapshot with a stable local permutation, response drafts, optional objective check progression, configured literal feedback, and practice calculation. Restart explicitly reads the current unsaved editor draft. Invalid/oversized question drafts and response shapes show an error instead of a fabricated result.

Backend and preview share bounded pure question validation, response validation, presentation projection and objective scoring. Server presentation retains cryptographic randomInt; practice shuffling is only local Math.random. Real authoritative grading still owns SQL, manual review, official score, completion and certificates. Weighted objective results match official backend calculations for the same original response meaning despite distinct permutations. Manual essays have no simulated score. Final pending manual practice withholds feedback; never-release stays hidden. Preview has no genuine attempt history, so exhausted-attempt release is not simulated.

The preview component has no invoke/mutate callback, session or persistence capability. It cannot create an enrollment, attempt, audit receipt, workspace revision, official score or certificate. Four pure-state/domain equivalence regressions and one actual browser unsaved-author/EN/VI mobile fixture prove shape rejection, snapshot immutability, progression invalidation, matching official scoring, manual pending behavior, restart, zero HTTP mutations and unchanged official tables. Exact-head CI pending. Rich question titles/formatting, previous-response and incorrect-only retries, explicit latest-quiz migration and reference fixtures remain OPEN.
