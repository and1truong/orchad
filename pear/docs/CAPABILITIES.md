Status semantics: PASS applies only to an explicitly tested sub-capability. FAIL means required code is absent/incomplete. BLOCKED names an external dependency. Unit test names are in tests/domain.test.ts, tests/authoring.test.ts, tests/http.test.ts and tests/host.test.ts. Browser/native/live outcomes are separately recorded in IMPLEMENTATION-REPORT.md.

## Phase accounting

P0: register, aggregate/security/content/role ADR and domain tool freeze implemented. Reference plan/portal selection is NOT VERIFIED.

P1: independent runnable Pear, migrations/seeds, ≥3 original courses, two learners plus manager/admin, catalog/save/enroll/player/MCQ/progress, admin draft/publish/assignment and Bridge 0.1 implemented. Standalone item/module authoring and a full editor for current bounded formats are implemented in the next stacked layer; authoring tests cover legacy migration, source/version pinning, module sequencing, egress, integrity and real human editing. Evidence is per lane, not a claim that P1 acceptance or full parity has passed globally.

P2–P4: remain open as listed above. No scope exception or automatic epic closure. Provider licenses, production identity, partner/native/channel accounts and deployments must be authorized and verified separately.

Program layer: ADR-003 records internal award/playlist policies, graph bounds, credit reuse, learner evidence confirmation, scoped moderation and immutable versions. This is partial P2 delivery; other P2–P4 rows remain open.

People layer: ADR-004 records identities, relationship constraints, custom fields, CSV review/hash/atomicity, safe exports and static/dynamic group behavior. G13 internal sub-capabilities are implemented; IdP provisioning remains a separate dependency.

Assignment layer: ADR-005 records distinct recurring ledgers, UTC cadence/deadlines, membership policy, live authority, bounded/fair jobs, private in-app notifications and migration preservation. Tests explicitly cover fresh recurring award proof and retained certificates; external delivery and reference-specific calendar/re-certification behavior remain gaps.

Media layer: ADR-009 documents internal uploads, byte/quota/CAS/atomicity limits, pinned read scope, opaque interactive origin and explicit production scanning/storage gate. Browser evidence covers playable original WAV/MP4, real Chromium-generated PDF download and running-but-isolated HTML practice. Submissions and award evidence PDFs are implemented in subsequent stacked layers.

Blended layer: ADR-010 records pinned submissions and event policy, slot identities/capacity across versions, timezone/cutoff, human-only grading/attendance, cancellation/membership seat release and private ICS. Internal file/calendar behavior does not claim external provider integration.

Award evidence layer: ADR-011 records private pinned PDFs, tenant/enrollment/criterion ownership, live assessor authority, duplicate-byte detection, optional human form/download and nullable legacy migration. File upload alone never grants award credit. Production scanning/storage and exact reference format coverage remain open.

Feedback/certificate layer: ADR-012 records human-confirmed version opinions, private feedback scope, aggregate-only agent reads, atomic mutation/history, and browser-generated portrait PDF certificates isolated from unrelated personal data. It makes no accreditation, benchmark, insight metric or server PDF delivery claim.

Standalone ledger layer: ADR-013 records exact-version tracking, human-confirmed reading, retained retired-source access, model/file egress gates and scoped item transcripts/reports. It never creates course/award credit, assessment score or a certificate.

Calendar recurrence layer: ADR-014 adds reviewed named-zone monthly anchors, original-anchor month-end clamping, explicit fold choice, forward gap resolution and calendar fixed deadlines while retaining elapsed rolling deadlines and legacy UTC-day plans. Fixtures cover restart and immutable delivered cycles. Exact reference recurrence semantics and external notification delivery remain open; current-head CI is required.

Study telemetry layer: ADR-015 adds explicit human study timers with bounded server intervals, session leases, gap exclusion and durable totals. Reports keep intended minutes, observed timer seconds, official scores and credits separate. This is observed timer telemetry, not verified attention or provider-runtime tracking. Full reference reconciliation remains open.

Content curation layer: ADR-016 adds explicit organization endorsed/featured/spotlight/retiring policy, bounded metadata discovery, live aggregate retirement impact and hash-reviewed same-kind replacement. Existing pins and assignment plans are never silently rewritten; unavailable alternatives return a reason. Provider lifecycle feeds and reference portal preferences remain open.

Native host evidence layer: ADR-017 adds a strict actual Tauri WebView → built Pear bridge/backend lane reached by an external client over the real Coconut MCP facade. It checks consent/approval, zero-dispatch denial, pinned progress, official-integrity boundaries and account revocation. Exact-head CI is required; the old counter lane alone remains insufficient evidence for Pear. No production origin or identity adapter claim.

Discovery layer: ADR-018 adds complete internal metadata filters, explicit authorized comparison, controlled-concept retrieval and declared-profile recommendations with reasons/source IDs. This is a bounded rule baseline; full semantic/assistant quality and provider taxonomies remain open. Publication dates are actual Pear transactions; legacy dates stay unknown and accessibility remains author-declared.

Timed caption layer: ADR-019 adds validated original plain-text WebVTT uploads, immutable source/version tracks, authorized human-only caption file access and native browser cues with keyboard-operable text transcripts. General WebVTT formats, caption quality and full screen-reader/mobile/WCAG audits remain open.

Interface localization layer: ADR-020 adds explicit Vietnamese UI labels/accessible names across major surfaces and independent persisted interface locale without translating authored source data or backend IDs. Provider language coverage/content variants, exhaustive diagnostic translation and linguistic/accessibility audits remain open.

Reviewed OIDC layer: ADR-021 adds an explicit signed Authorization Code/PKCE profile, admin-owned subject mappings and live revocation with loopback domain/HTTP/browser fixtures. Actual IdP sandbox, provider-specific/SCIM/logout profiles and production deployment remain BLOCKED/NOT VERIFIED; no credentials or account were configured.

Scoped provisioning layer: ADR-022 adds expiring human-issued read/write credentials and a bounded client-owned SCIM User/static Group profile with live authority, ETags, exact reconciliation, session revocation and retained learning history. Actual provider sandbox, enterprise schema/filter/PATCH compatibility, invitations and production deployment remain BLOCKED/NOT VERIFIED.

Signed event layer: ADR-023 adds organization-scoped metadata event reconciliation, transactional enrollment/course lifecycle events, pinned server endpoints, signature/timestamp verification and an ordered durable lease/retry outbox. Real loopback receiver fixtures distinguish network delivery from mocks. Actual external receiver/partner conformance, retention/compaction, notification/item/award topics and deployment remain OPEN/BLOCKED/NOT VERIFIED.

Language identity layer: ADR-024 adds canonical authored content identity, exact-version reviewed en/vi derivatives, provenance/disclosure, explicit original fallback, current course discovery deduplication and human language preview selection. Published changes require new review and never transfer existing progress/credit. Licensed provider translation pipeline, full language list, linguistic audit and equivalence remain OPEN/BLOCKED/NOT VERIFIED.
