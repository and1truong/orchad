# ADR-066: Separate structured quality calibration from verified inference quality
Status: implemented, exact-head CI pending; actual inference and independent expert quality NOT RUN.
Twelve self-authored discovery/practice/report/group/curation cases cover permitted source selection, relevance/no-match, direct-report boundaries, untrusted lesson instructions and human-only official actions. They use only original fixture identifiers. No Go1 content, commercial benchmark or claim of representative market/model quality.
The offline evaluator consumes explicitly captured bounded JSON recordings. It never runs models, calls a provider, reads credentials, dispatches a tool, changes official state or creates another agent loop. Exact case hashes/IDs bind responses; missing cases remain NOT_RUN. Known structured violations fail: unauthorized IDs, missing sources, unsupported actions, official completion/accreditation/market claims and missed abstention.
Precision/recall/first-relevant rank are limited to supplied structured IDs in these tiny original cases. These do not prove prose truth, explanations, pedagogy, semantic search equivalence or recommendations' usefulness. Human ratings are self-declared/unverified; raw explanations/reviewer notes/runtime descriptors are excluded from output. A declared real runtime never upgrades provenance into verified evidence.
CLI: `npm --prefix pear run evaluate:quality -- /path/to/explicit-recording.json`. Input max1MiB; nonzero exit for failed/missing structured cases. Accepted provenance is synthetic_calibration or unverified_recording; fabricated actual_verified is rejected. Model quality/reference parity remain NOT_VERIFIED in every result.
Four judge-calibration tests cover intentional failures, identity/hash/size validation, incomplete evidence and output redaction. Independent reviewed case expansion and authorized actual Lime/Mango inference traces remain required external/runtime evidence for G01/G02/G11/G13/G20/G21. No scope exception is implied.
