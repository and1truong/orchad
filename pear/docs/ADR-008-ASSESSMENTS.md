# ADR 008 — Typed assessments and human essay moderation

Status: internal MCQ/matching/blanks/long-answer workflow implemented. Advanced question banks and reference-specific completed-learning reset policies remain open.

Published course versions contain typed bounded questions, points and optional shuffle/release policy. Legacy questions default to MCQ and one point. Matching is one-to-one with distinct choices; blanks use exact NFKC/case/trim normalization against authored expected words. Long answers require a rubric and a delegated human assessor. Objective partial credit and essay points use integer units with denominator 840 (divisible by every supported 1–8 response count), avoiding floating rounding at pass thresholds. Final percentage is floored only once.

Attempt question/option presentation is randomized with Node cryptographic random integers when enabled, then persisted. Display-index answers map back to the pinned key; retries/restarts retain the same presentation. New attempts get new presentations. Draft answers are type-validated and saved explicitly; matching/blank partial drafts can persist but cannot be submitted incomplete. Quiz content is at most 16 KiB and combined saved responses at most 32 KiB so human/player/moderation envelopes fit the canonical 64 KiB limit. Oversized saves preserve the prior draft atomically.

Only the human controller accepts answer saving/submission, rubric grading and retry allowance. Agent catalogs expose course-assessor delegation and scoped queue metadata in the assessments domain; they cannot read essay bodies, release answer keys, supply rubric grades or confirm learning. Own agent attempt reads withhold saved responses and all objective keys/rubrics. Licensed-content processing restrictions still apply. Human feedback release is pinned when an attempt is finally graded, after passing or exhausting allowed attempts according to the version's policy; subsequent retry allowances do not revoke already released feedback.

Submitted essays remain pending_manual with null score/pass. No completion or certificate is created before every essay has a final review. Scoped active assessors and tenant administrators read submitted essay/rubric details; content admins can delegate active same-tenant assessors but cannot read learner submissions by that role alone. Every review rechecks current delegation, role, tenant and obligation state before dedup and under transaction. Question reviews are final and immutable; committed retries return the original result. Objective and reviewed points produce the backend's official grade. Passing also updates learner progress, nested award credit and private completion notices in the existing atomic learning controller. An audit failure rolls back review, grade, certificate and revisions.

Admin retry allowances grant 1–10 additional attempts to unfinished active learning, capped at 100 extra total. Existing submissions, scores and certificates are preserved. Pending drafts/reviews must finish before a new allowance; completed learning is not reset or un-completed by this tool. Re-certification uses separate scheduled ledgers. Actual reference reset/retake semantics need further evidence before parity closure.

Migration 007 adds presentation/grading/feedback state, delegated assessors, immutable essay reviews and retry allowances. Prior submitted MCQs become graded without changing their answers, scores, enrollments or certificates. Human editor/player/review UI implements all four question types and the supported policies. Tests cover partial scores, no early certificate, live revocation, private/model channels, atomic rollback/dedup, persisted order/rubric/reviews, migration and UTF-8 budgets.

This layer is based on codex/pear-tool-groups-49 (PR #66), continuing #49. Pear has no AI provider SDK or model grading path.
