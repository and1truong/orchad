# ADR-074: exact award criterion course bindings and reviewed fresh learning

2026-10-07. Epic #49/G06/G08/G09, integrated into the existing #132 delivery branch. Supersedes the three internal OPEN items in ADR-073; preserves its fail-closed legacy behavior for ambiguous calls.

A binding identifies **award enrollment + immutable criterion path + course**. It records the original published course pin, an explicitly reviewed current version, a current official enrollment pointer and a revision. Nested paths include immutable child award versions. Selecting a path selects its original pin; no highest-version inference occurs. Legacy opening without a path works only for one unambiguous reference and uses the same controller. Ordinary course roots remain separate. An old opening receipt cannot return a superseded pointer.

Migration 042 adds binding and review tables and a nullable enrollment binding FK. Existing IDs, immutable content, attempts, certificates, integration triggers and other dependent FKs are preserved. Existing direct/cycle root uniqueness remains for unbound learning; each binding has its own root and immutable successor chain. Legacy matching records can be referenced without rewriting their history. A mismatched legacy record requires an explicit fresh review, never silent adoption of its completion.

Self-directed learners choose an exact lawful published version and confirm fresh learning. Assigned obligations require the current coordinator's offer followed by a separate addressed learner acceptance of that exact version and binding revision. Offers expire after 24 hours; the coordinator can cancel a pending offer and create another explicit offer. Pending grades/submissions and booked events block both offer and acceptance. Assessors resolve pending work through the existing reviewed grading routes; learners explicitly cancel bookings through the existing cancellation route. No grade, attendance, lesson, response, timer or completion is copied. Completed source rows and certificates remain unchanged; unfinished owned predecessors are withdrawn from new official writes.

Assigned fresh records retain award assigner, due date and original cycle. Neither the immutable award graph nor the cycle/plan/future pins are changed. Scheduler leave/rejoin/cancel follows current bound children, preserves archived predecessors and rechecks the original and reviewed course audiences even when the latest published version becomes tenant-visible. The usual inactive-booking release policy still applies to revoked obligations.

Current account/tenant, learner, coordinator/direct-report relationship, dynamic cycle membership and original/current/target content audiences are checked inside the write transaction before original-key receipts. CAS, semantic payload identity, successor pointer validation, counterpart revisions, idempotency and redacted audit share the transaction. An audit failure rolls back offer/acceptance, withdrawal, new enrollment, pointers, revisions and receipts. Review history has a 5,000-row per-tenant operational bound; it does not change publication/history retention.

Course proof requires the same learner, tenant, exact reviewed version, current binding enrollment and exact award cycle, plus completion after cycle start. Without a binding, proof still requires the exact version and assignment cycle when assigned, plus cycle freshness. Original and reviewed group rights are live gates for pending award credit. Completed original award certificates stay historical facts, not automatic future-cycle proof.

Human review tools are absent from bridge/model catalogs. Bridge opening accepts an explicit path under the existing bounded catalog and canonical 64 KiB envelope. EN/VI controls disclose original/current pins and fresh-learning semantics; version selection starts empty and each human has a separate confirmation. No model can accept a migration or supply official answers/completion.

Acceptance: `tests/award-bindings.test.ts`, existing award/course/opening/scheduler/retake/security suites, and actual learner/coordinator EN/VI journeys in `tests/e2e/award-bindings.spec.ts`. Migration tests use nonempty SQLite and actual reopen. Exact-commit outcomes belong in the delivery evidence ledger; authored tests alone are not PASS.

Full reference reset/recertification/reuse equivalence, unrestricted languages/formats, accreditation, model quality, conformance and real licensed/identity/partner/channel/production dependencies remain open in the current gap table. This decision implements the original reviewed policy and does not declare full parity.

Completed awards now persist an immutable accepted graph snapshot at issuance. Migration 042 adds snapshots without rebuilding ledgers; legacy certificates are backfilled from the available historical ledger at upgrade with `legacy_ledger_at_upgrade` provenance and an issuance cutoff. Old records did not preserve every prior assessor transition or audience decision, so this backfill cannot reconstruct missing historical facts or claim a prior exact issuance snapshot. New issuance captures the actual accepted graph; later completions, group changes and course publications do not recalculate the issued certificate. Nested child audience and active root recipient rights remain live gates before new credit/issuance.

The integrated review also fixes bounded overdue scheduler catch-up before end-window closure, lifecycle events at assigned insertion, webhook grant invalidation/fair claim cursor, source-item withdrawal for new course learning, human-only caption identifiers, booked-only meeting links and retry eligibility. Historical cancelled bookings lacking a cancellation timestamp retain their rows; the UI does not offer an unverifiable cancelled calendar.

Nested ancestor original/current audience is checked before opening, reviews, original receipts and official child writes; scheduler withdrawal/rejoin follows that same graph. Own immutable historical course reads retain current content/graph rights without depending on an old coordinator staying active. Actual v41 issued-award migration/reopen records `legacy_ledger_at_upgrade` provenance.
