# ADR 036: operational session cancellation and rescheduling

G07 now has explicit scoped future-session lifecycle mutations, separate from immutable course publication. Published course/session definitions and attendance history stay pinned. A bounded operational history (100 revisions) stores complete validated replacement definitions for the same session ID. Admin/content author scope and delegated instructor scope are checked before replay and inside the domain transaction.

Cancel/reschedule cancels every active booking, records a stable cancellation timestamp and sequence, emits one own in-app notice per affected enrollment, and increments affected learning workspaces. No automatic rebooking, attendance, grading, completion or certificates occurs. Learners explicitly choose a new available booking; capacity, cutoff, prerequisites and active-obligation checks use the current effective definition. Attendance and calendar export use the specific definition revision associated with the booking.

The library mutation, booking cancellation, notices, minimal public session.changed outbox fact, audit, operation key and revisions commit atomically. Invalid definitions, stale revisions, audit failures and revoked instructor scope leave no effects. Private course events are suppressed. Bridge reads omit room/meeting URL; human author and learner controls expose scoped operational details.

Cancelled own bookings remain exportable as RFC 5545 VEVENT records with the original booking UID and dates, stable DTSTAMP, increasing SEQUENCE and STATUS:CANCELLED. This is a downloadable calendar record, not organizer-driven iTIP scheduling or a proven external-calendar update. No external delivery, recipient identity, calendar subscription, integration credentials or notification install is claimed. In-app notices are persisted own-only facts and contribute to own digest unread counts.

Validation: four domain/actual HTTP tests cover cancellation, rescheduling, explicit rebooking/capacity, immutable content, actual attendance, private notices, cancelled calendars/DST, author/instructor/tenant scope, revocation before key replay, CAS/conflict, audit rollback and private/minimal outbox facts. A browser test exercises actual human schedule controls, notices, explicit rebooking, cancellation, calendar download and a Vietnamese label. Exact-head CI evidence will be recorded after execution.
