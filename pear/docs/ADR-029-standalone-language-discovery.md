# ADR 029: Standalone language identity discovery
Epic #49 G01/G04/G16, extends ADR 024.

Published standalone search applies explicit query/language filters first, then collapses active exact-version human-reviewed translation identities. Within matching candidates it prefers the requested language or own declared profile language; otherwise a matching original remains available. Selecting a variant is still an explicit source preview, never a transfer of enrollment/progress/credit. Invalidated review versions become separate sources until reviewed again; retired or outside-tenant sources are absent.

Human discovery retains human-authorized metadata; model discovery continues to withhold asset IDs, captions and restricted outcomes/body. Total/offset/pagination describe collapsed rows. The existing reviewed-language selector discloses original/fallback/provenance. Course and standalone credit ledgers remain independent.

Domain evidence checks EN/VI preference, query/language ordering, outside-tenant and body/asset leakage, invalidated review/retirement and unchanged original item enrollment pins. Exact-head CI determines PASS. Licensed provider variants, wider language coverage and linguistic quality auditing remain BLOCKED/NOT VERIFIED.
