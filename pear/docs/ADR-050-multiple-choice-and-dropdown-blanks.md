# ADR-050: Original multiple-answer choices and dropdown blanks
Epic #49 G06/G12/G16. Current official guide reviewed 2026-10-06: https://help.go1.com/en/articles/16936766-create-and-edit-quizzes

Original MCQ supports one or multiple correct indices. Exact scoring requires every correct choice and no wrong choice. The explicit partial policy is correct selected choices divided by all correct choices, without subtracting for wrong selections. Authors see this formula before publication; selecting all options earns full partial credit under this policy. The public guide does not specify a complete negative-selection formula; exact reference scoring still needs a verified reference fixture. Default is exact, and existing single-answer behavior remains unchanged.

Per-option selected/not-selected feedback is literal original text and hidden with correctness keys from learner bridge and unreleased human reads. Configured graded release includes only each option's relevant feedback branch; pending manual assessment remains withheld. Stored option permutations govern grading and feedback, never current mutable draft order. Whole question/form responses remain subject to existing quiz/course/response/message budgets.

Blank questions can mix free text and dropdown rows. Each dropdown has distinct 2–8 original choices including its accepted answer; options shuffle per attempt and persist across reload. A supplied dropdown value outside its list rejects; free-text normalization retains existing Unicode/case handling. No provider material or automatic translation enters this authoring flow.

Long-answer questions can declare a 0–100 correctness threshold, default 100. An authorized numerical rubric score still contributes its earned fraction to the overall weighted score even if the question meets its correctness threshold. Correctness and official completion are distinct; pending review never becomes a score, and learner model reads receive no reviews/keys/feedback. Existing optional question weights remain a Pear extension; default equal weights match the guide's ordinary profile, while weighted mode is not exact reference equivalence.

Four golden/randomized/domain/actual HTTP regressions plus one author/learner EN/VI mobile browser fixture authored; exact-head CI pending. They cover shuffled exact/partial results, dropdown/free answers, malformed settings, key/feedback egress, manual correctness versus numerical contribution and audit rollback. Per-question progression/release, incorrect-only retries, interactive author preview and explicit latest-quiz migration remain OPEN. Full reference rich formatting/question titles, precise partial-credit fixtures and accessibility/linguistic audit also remain OPEN/NOT VERIFIED.
