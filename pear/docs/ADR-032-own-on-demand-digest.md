# ADR-032: Own on-demand next-step digest
A bounded deterministic read joins the learner's own active, incomplete pinned course/award enrollments. Overdue and due obligations precede assignments and self-directed learning. Course next lessons require satisfied pinned prerequisites; all-complete lessons refer to official human assessment review without inventing a score. Withdrawn/cancelled obligations and completed records are excluded; unpublishing does not erase enrolled pins.
Five steps maximum; each enrollment family scans six leading candidates, with an explicit more-pending flag. Budget fitting uses whole intended course duration, never guessed remaining time or observed study. Recommendation fallback considers at most ten declared-preference results from existing live authorized discovery and exposes that bound. No-match language names this window.
Deadlines retain exact UTC values plus an explicitly chosen validated IANA time zone. DST conversion uses Intl; no calendar event or provider connection is created. Notification count has own tenant/learner scope, without copying titles or contacts into the digest.
Human My learning includes an explicit on-demand digest panel; Lime planning guidance names the same read tool. No model/runtime is added to Pear and no scheduler, DM recipient, message or automatic delivery is introduced.
Evidence: deterministic domain cases, role/tenant/privacy and source bounds, prerequisites/pins, inactive/completed exclusion, time-zone/DST and intended-duration limits; actual browser panel evidence. Exact-head CI pending.
Remaining G22 work: consented real channel adapters/DM isolation, delivery lifecycle, selected calendar integration, durable Pear workflow recovery and model plan usefulness.
