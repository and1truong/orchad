# Explicit latest objective quiz upgrade

Unfinished self-directed objective courses may explicitly choose a newer published quiz only when all nonquiz course structure/content is identical. A successor enrollment retains identical completed lesson IDs, starts with no answers/attempts and withdraws its source from further official mutation. Source version, failed grade, responses and all evidence remain immutable. Human confirmation, exact latest version, ownership/live old and new content rights, personal CAS/key/audit transaction apply.

Assigned courses/cycles, events, submissions, essays or other course changes are unsupported and require separately reviewed migration workflows. Completed-course retakes remain independent. No auto-upgrade, scoring, completion or certificates. Existing retake lineage/index supports one successor without a new migration. This is original bounded quiz-only behavior, not a full migration/parity claim.
