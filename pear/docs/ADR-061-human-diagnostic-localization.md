# ADR-061: Localize known human diagnostics without changing the wire
Status: implemented; exact-head CI pending.
The human UI translates 522 known diagnostic literals into Vietnamese when selected, preserving machine-code prefixes. English remains the default. Unknown messages, authored text, dynamic composites and prototype keys remain literal; React renders text safely.
CanonicalBridge describe/context exceptions and invoke Result payloads retain their original English. Transport/policy tests compare the wire result directly. No catalog/schema/byte limits, ACL, epoch, CAS, receipts or official learning rules change.
A lost or truncated human mutation response is an unknown outcome: refresh current data before confirming another action. The transport never automatically replays it. This warning does not establish whether a server commit occurred. Bridge keeps its existing reconciliation result.
Four domain/transport tests and one real browser negative test cover the selected profile. The browser submits a foreign reference, checks English wire versus Vietnamese alert, and verifies no destination draft, workspace revision or offer-state change. This is not exhaustive runtime localization, professional linguistic review, model quality or full reference parity.
