# ADR-067: Restart a latest self-directed course from zero after full-change review
Status: implemented, exact-head CI pending.
This adds a separate human-only fresh-course choice beside the existing objective-only choice that retains identical lessons. The latest title/summary/version/lesson count/types are reviewed explicitly; the learner confirms no carried lessons, answers, submission results, attendance/bookings or measured time. Old pinned official records stay immutable in withdrawn history. New work starts empty/in-progress and only subsequent human work/assessor decisions can complete.
Both old/current content rights, current account, own unfinished active self-direction, exact latest published target and absence of unresolved official work are checked before receipt lookup inside IMMEDIATE. Submitted pending essay/manual grading, pending submissions and booked events block restart. Existing human assessment/cancellation must resolve them first; a new version does not silently cancel work or impersonate an assessor. Resolved failed essays/submissions and explicitly cancelled bookings remain historical.
Atomic source withdrawal/successor/receipt/redacted audit and the existing one-successor index apply. Same original-key retry requires current rights/target and matching already-created successor; new-key duplicate and moved latest target are denied. No schema/canonical/message/host bounds change and no migration is needed.
Seven domain tests cover actual failed objective history, pending/resolved human essay/submission, real upload evidence, booked/cancelled event, authority/replay/CAS/audit rollback and reopen. One real EN/VI browser journey covers explicit full-change review and fresh zero progress. Assigned/cycle full changes still require a separate coordinator workflow; exact reference/reset/recertification semantics remain OPEN. This is an original reviewed policy, not a Go1 compatibility claim.
