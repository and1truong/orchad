# ADR-062: Two-party objective quiz restart for direct assignments
Status: implemented, CI pending.
An unfinished directly assigned course may restart only when the published latest version differs solely in objective quiz configuration. Event, submission, essay, nonquiz edits and assignment cycles are rejected. The current assigner-manager with a live direct-report relationship, or a current tenant administrator, explicitly offers; the addressed learner separately reviews and confirms. An offer alone changes no official learning.
Offers expire after 24 hours and are bounded to 5000 tenant records. One offer per source/version is retained; expired or revoked offers cannot be renewed for the same version in this profile. That renewal workflow remains OPEN.
Current active learner/coordinator, role/relationship, source state and both old/latest content rights are checked inside the same IMMEDIATE transaction before operation receipt lookup. Accepted original-key retry is allowed only with the same current authority/target and a matching successor; a new key is rejected. A moved latest version, expired offer or revoked authority fails closed.
Acceptance withdraws the prior unfinished record, creates one successor with the same due date/assigner/completed identical lessons, and starts empty answers. Prior versions, attempts and results remain immutable; only subsequent human submission can complete. Library and learner revisions, receipt and redacted audit are atomic. No cycle delivery pointer is modified.
Five domain tests and a real two-role EN/VI browser test cover this bounded original policy. This is not exact reference migration semantics, cycle support, production account verification or full G06 parity.
