# ADR-070: Original pinned standalone reading can satisfy an award criterion
Status: implemented candidate, exact-head CI pending.
Primary comparison: https://help.go1.com/en/articles/16062130-create-and-edit-awards (retrieved 2026-10-06) lists standalone content among award items. This implementation reuses Pear's existing lawful versioned item references and human-confirmed reading ledger. It does not invent an assessment grade or call reading a course assessment.
The bounded award schema now accepts item alternatives. Publishing snapshots their exact authorized version, using existing tenant/current/pinned audience and redistribution checks. Pending/unpublished/private or unrelated items cannot be laundered through publishing. Only this learner's real completed item_enrollments row for that exact version qualifies, with live pinned/current content rights. Other learners/different versions/unconfirmed tracking do not contribute. For a scheduled award, completion must be on/after that cycle's run time; an old record cannot satisfy a later cycle.
An item completion invokes existing authoritative award refresh and cycle completion notifications in the same CAS/receipt/audit transaction. Required/elective/ongoing/one-item and actual nested quantity rules remain existing deterministic policies. Human-only reading remains human-only; an external evidence claim does not replace an item proof. Issued prior award history remains preserved.
The learner can choose the pinned standalone version in award progress, open it in the existing tracked reader and separately confirm studying it. EN/VI explanation explicitly distinguishes reading proof from assessment. No new bridge tool, contract/profile cap or migration is added.
Six domain tests and one actual EN/VI browser journey cover exact proof, role/channel/version/audience denial, publication boundaries, same-transaction rollback, cycle timestamp freshness, nested/reopen and required/ongoing/one-item behavior.
Fresh same-version standalone retakes for a later recurring cycle are still OPEN: tracking an already completed version returns its existing record, and cannot manufacture a new completion date. Reference accreditation, item-specific passing semantics, external-learning rule availability, grouping/reset/recertification, commercial catalog and exhaustive accessibility/linguistic review remain NOT VERIFIED/OPEN.
