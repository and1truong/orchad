# ADR-055: One-criterion awards and original custom quantity names
Epic #49 G05/G07/G12. Base PR #113.

Optional completionMode selects the existing target-plus-required rule or completion of one configured criterion. Each criterion may contain bounded alternative course/nested-award/external references; full criterion credit is needed. One-item rejects required flags explicitly, and the editor clears/disables them. Numeric target is retained but not used for one-item; the player displays the actual one-criterion rule. Ongoing overrides either mode and never completes automatically.

Custom units require bounded nonblank original singular and plural names. They are presentation labels on existing integer quantities, not unit conversion, accreditation or inferred training hours. React display and certificate text/print preserve them literally. Existing built-in credit/hour labels retain their prior behavior. Published and enrolled versions keep original names/rules after draft edits.

Pending/rejected or partial evidence cannot complete a one-item award. Existing scoped moderation or disclosed human self-attestation policy remains authoritative; one-item introduces no automatic evidence acceptance. Evaluation, certificate creation, workspace revision, audit and original receipt remain atomic, with current authority before replay. Existing group/tenant/source/reference/nesting/byte bounds remain unchanged.

Five domain/moderation/audit/SQLite reopen regressions and one actual author/learner EN/VI mobile fixture are authored; exact-head CI pending. The original one-criterion alternative profile is explicit; precise reference semantics of required flags and richer item grouping need fixtures. Actual nested-child credit accumulation, primary-assessor assignment/reassignment, cross-portal sharing, genuine external channel installations and production/reference/a11y audits remain OPEN/NOT VERIFIED.
