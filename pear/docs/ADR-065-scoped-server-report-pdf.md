# ADR-065: Download a server report using the exact export scope
Status: implemented, exact-head CI pending.
The report download uses the existing typed specification, filtered/all-within-current-access rows and visible/all columns. It reviews the exact export scope's snapshot before download, then server rechecks current administrator/direct-report authority and recomputes that same scope/hash. No submitted rows, arbitrary SQL, saved-report ownership transfer, learner impersonation or learning mutation.
POST requires current cookie/epoch/CSRF/Host; bounded JSON schema, current role/auth version and audience gate the PDF. Learner/content-admin/assessor cannot access admin export. Report data/filter/audience changes abort rather than downloading a mixed snapshot. Tenant administrators still cannot export other tenants.
The existing original trusted-font PDF engine handles scalar columns with literal authored text. Limits remain 500 records/65536 characters/40 pages/4MiB; selected columns may reach document limits earlier. CSV/browser print remain alternatives. Header records requester/snapshot/scope and development/no-accreditation disclosure.
Four domain/HTTP/scope/real-reader tests plus a real manager EN/VI browser download cover this bounded original export. Production font, exact reference layout, PDF/A/tagged/accessibility auditing and real export delivery connectors remain NOT VERIFIED. No model quality claim.
