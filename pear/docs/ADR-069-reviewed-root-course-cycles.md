# ADR-069: Review a latest course version for one root cycle delivery
Status: implemented candidate, exact-head CI pending.
The current active plan owner with live direct-report scope or an administrator offers an exact objective-only/full-course mode. The addressed learner separately confirms. Only active unfinished root course deliveries qualify; award-cycle children, completed/cancelled/withdrawn deliveries and blocked/cancelled plans fail closed. Closing a plan stops future scheduling while its active obligation remains reviewable. Dynamic frozen-cycle membership and both old/latest content rights are current checks before receipts and inside the transaction.
Migration 040 keeps one original root enrollment per cycle and uses existing unique retake chains for reviewed successors. It adds nullable review/original-enrollment references to delivery rows. A confirmed successor retains cycle, original assigner and due date; objective-only retains identical lessons and full-course carries zero progress. Pending assessment or bookings block full-course acceptance. Source is archived withdrawn without changing answers/results. Only that learner delivery pointer moves; cycle definition/version and future plan/cycle pins remain unchanged.
Original-key replay additionally requires the exact current review/delivery/successor pointer and current authority. Later cancellation/completion/replacement cannot replay earlier authority. Delivery pointer, source/successor, review, revisions, receipt and redacted audit are atomic. Existing six-column delivery insertion now names its columns for migration compatibility.
The scheduler checks the current delivery's actual pinned course version. Reconcile/cancel bulk updates exclude ancestors with successors, so leaving/rejoining cannot reactivate archived learning. Completion follows the current pointer and deduplicates by cycle/learner. No award proof is broadened.
Eight domain tests use actual scheduler deliveries, exact-mode/agent gates, fixed/future pins, dynamic leave/rejoin/cancel, reviewed-version audience despite open original/latest versions, resolved essay, current-owner authority, closed-plan completion notifications, rollback, award-child exclusion and a real nonempty 039→040 migration/reopen. The older 037 migration fixture faithfully rewinds its empty delivery schema before upgrading through 040. One real two-human EN/VI browser test checks the cycle explanation and current pointer.
This is an original bounded course-cycle review policy, not verified Go1 reset/recertification semantics. Award-cycle/latest award changes, exact reference policy, production providers, independent linguistic/accessibility review and actual model quality remain OPEN/NOT VERIFIED. No merge/deployment or external integration.
