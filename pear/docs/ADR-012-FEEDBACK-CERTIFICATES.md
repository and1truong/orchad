# ADR-012: Voluntary ratings, private feedback and printable certificates

A rating is a voluntary learner opinion and is separate from an official assessment score. A learner may submit or update one rating (1–5) and optional written comment (≤1,200 characters) per completed own course version. A later recurring enrollment for the same version updates that opinion instead of inflating the aggregate. The backend requires persisted quiz-derived completion and explicit human confirmation; agent catalogs contain no feedback mutation. No rating changes lesson progress, attempt scores, award credit or certificates.

Feedback uses personal workspace CAS, principal/tenant/live account authorization before key reconciliation and inside the existing immediate mutation transaction. Exact retry returns the original result; changed payload conflicts. Rating, comment, revision, key and audit commit atomically. Operational audit records only enrollment ID and rating, not the private comment. Migration 011 adds the opinion ledger without changing existing completed learning.

Own feedback is a human-only read tied to the completed enrollment. A tenant administrator can read a bounded version-scoped human feedback page. Managers, Content Admin and delegated assessors cannot access written feedback. Agents can read only count/mean for one visible course version, with no learner identities or comments. Published versions remain separate; retired history remains readable to its completers or tenant content administrators. There is no public comments feed, inferred sentiment, benchmark data or provider metric claim.

Course and award certificates retain the authenticated backend certificate identity, pinned title/version, issue timestamp and explicit synthetic issuer/non-accredited disclosure. The UI prepares a portrait A4 certificate for the user's browser Print / Save as PDF dialog; it is not a server-generated PDF or accredited issuance API. Award output includes earned credits/hours. Existing plain-text downloads remain available. Browser Unicode rendering preserves Vietnamese.

Printing uses one explicitly marked, mounted DOM view. Preparing a report or certificate clears the previous print marker; print styles hide all other content and controls. Certificate printing does not include learning lists, private feedback, evidence or unrelated report rows. The report snapshot continues to use its authorized selected rows/columns and landscape A4. Session/view unmount removes the mounted print view. No private file or model transport is added.

Validation covers completed/own/tenant/channel permission checks, withheld comments, version counts, rating edits, exact-key conflict/retry, audit rollback, retained certificates, disk reopen and inactive principal denial. Real human browser journeys save/reload Vietnamese feedback, review it as admin, and generate actual course/award PDFs; extracted PDF text proves title/identity retention and exclusion of unrelated learning/evidence/feedback. These are internal synthetic fixtures. Complete reference feedback workflow, skill/content insight definitions and accredited/market benchmark datasets remain open.
