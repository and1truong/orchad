# ADR-071: Human chooses a new same-version standalone reading record
Status: implemented candidate, exact-head CI pending.
This original policy closes the internal inability to supply fresh reading for a later award cycle. A human reviews an own completed pinned version and confirms starting a new record for that exact version. No completed date, timer or award credit is copied. Original reading and issued awards remain unchanged; a new real human confirmation is still necessary.
Migration 041 rebuilds the item ledger without changing historical IDs or their dependent study/media/report references. Original version roots stay unique; each completed source has at most one successor linked by retake_of. Startup disables FKs only around the trusted migration transaction, checks all FKs before committing and restores enforcement on success/failure. No production table or data deletion outside this lossless migration.
Current account, own source completion, exact version, published source and pinned/current audience apply before original-key lookup and inside the IMMEDIATE transaction. New-key duplicates/incomplete source/other learner/agent/false confirmation fail. The original receipt never restores access after retirement or group revocation. Ordinary tracking returns the most recently created same-version record, so it resumes the current successor rather than silently creating another.
Human-only tool remains absent from the bridge catalog. Retake summaries expose only own successor IDs and current availability. UI discloses empty fresh progress and retains a separate reading confirmation; no hidden reset or automatic completion occurs. Audit stores only source/new item IDs, pinned version and confirmation.
Five domain tests plus one real EN/VI browser journey cover no carried state, role/channel/version/audience/retirement replay, audit rollback, actual later-cycle fresh proof and deduplicated notices, nonempty 040→041 migration with dependent study FKs, transcript and restart. Trusted tests arrange original historical completion timestamps for the cycle boundary; production completion always uses server time.
This is a bounded original reading-attestation policy, not verified reference assessment/accreditation or Go1 reset/recertification semantics. Licensed catalog, item-specific graded completion, broader reference semantics and independent accessibility/linguistic quality remain OPEN/NOT VERIFIED.
