# Implementation report — Guava

Date: 2026-10-05. Repository: and1truong/orchad, scoped changes under guava only. This implements Prompt 4; no extension, gateway, desktop host, provider adapter or production agent loop is built here.

## Implemented

- React/TypeScript + Vite + XYFlow infinite canvas with document list, pan/zoom, multi-selection, node/edge editing, inspector, explicit edge kinds, deterministic layout and revision-aware undo.
- Fastify serves production assets and API from one origin; configurable port defaults to 4310. SQLite migration and repeat-safe startup seeds persist graph data, ACLs, sessions, deduplication, history and audits.
- Two synthetic seeded documents and seven evidence records containing supporting signals, counterevidence and competing explanations. Synthetic UI labels; no authoritative root-cause button.
- Server-side development login for reader/investigator, scrypt passwords, hashed opaque session cookies, exact Origin + session CSRF protections, secure deployment cookie option and backend ACL checks.
- Domain services are independent of React. Human mutations and bridge dispatch share the same API/service. Proposal defaults to proposed; only a separate human UI/API action can accept, and that action is absent from bridge tools.
- Seven bounded tools through the exact Agent App Bridge 0.1 describe/getContext/invoke interface. Schema checks reject additional identity/approval fields. Context is short and excludes credentials.
- One SQLite transaction for batch graph validation, expected revision, write, snapshot, completed idempotency response and success audit. Deduplication is principal/document/key scoped and checked before stale revision comparison. RequestId is correlation only.
- Undo of the explicitly identified latest mutation restores document data with a new revision; intervening changes reject the operation.
- Independent dev-only host simulator using the actual bridge: discovery, runtime-origin target, document/session instance binding, consent, exact batch approval, denial, expiration, replay, stale requests and invalidated targets. Label: scripted simulation, no LLM.
- Portable JSON shared demo_increment scenario, executable test double and a real unsupported HTML page without a bridge.
- Optional native draft WebMCP registration adapter against verified Chrome documentation. Uses the same registry/host dispatch, no polyfill, not auto-enabled.
- Configurable external host integration SDK client, lockfile, Dockerfile, tool catalog, security notes, README and screenshots.

## Mock-only versus live

The shared counter is a test double, not the backend authorization implementation. HostSimulator is a scripted same-origin development harness, not a production trusted extension/native host. Native WebMCP adapter registration is tested with a fake runtime API and never presented as native support. SQLite domain tests and Chromium app/harness tests operate on the real implemented app.

## Assumptions and limitations

- The main repository file is named `contract`; its content is copied verbatim into guava/CONTRACT.md. Its actual SHA-256 differs from the prompt's declared digest; details are in CONTRACT-CHANGES.md. No shared method or field is renamed.
- Development auth is intentionally limited to two fixture accounts. It is not suitable as public production identity; production login throttling, account provisioning and SSO are not implemented.
- Human acceptance is an explicit application action, not cryptographic proof of human presence or verified factual truth.
- The frontend uses three-second reconciliation polling and rejects concurrent stale writes. No CRDT or real-time collaborative merge is claimed. The toolbar's last undo pointer is page-memory state; persisted mutation IDs remain usable via tools after reload.
- History, audit and idempotency records have no retention policy. Undo only affects SQLite documents; no external side effects exist.
- Canvas maximum is 500 nodes / 1000 edges. Layout uses stable type columns rather than a full graph optimization algorithm. Graph tool pagination must restart if the revision changes between pages.
- The native adapter is not automatically included/enabled by the production entry point. A verified native host must own dispatch, consent and approval before opting in.
- Loopback browser/native host integration remains optional and unrun; compatibility is based on the shared bridge tests, not a claimed live host result.
- The normal Playwright Chromium CDN returned truncated/non-zip data. A real Chromium binary was obtained from the pinned @sparticuz/chromium 153.0.0 npm distribution for these tests. No binary/runtime helper is committed or added to app dependencies.
- Vite emits an XYFlow module-level use-client directive warning; this client-only SPA built and passed real browser tests. Node runtime scripts use node --import tsx to avoid an environment restriction on the tsx CLI's IPC pipe.

No public deployment, package publishing, paid API call, other repository mutation or main-branch merge was performed. The reviewable deliverable is the Guava feature branch/PR.
